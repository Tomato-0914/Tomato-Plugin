查询条目

武器、圣遗物、食物、敌人、秘境、角色都支持；名称的一部分也能模糊匹配（比如"雾切"→雾切之回光）

#护摩之杖图鉴或 #图鉴护摩之杖，最标准的写法，哪个分类都能查
护摩之杖不带 # 也不带"图鉴"直接发也能查，但只对 {{bareCategories}} 这几个分类生效，且名称/别名/料理名要完全对上
#原石图鉴道具类，以及原石、摩拉、鸟蛋这类容易和闲聊撞车的日常词，只认"带 #"或"带图鉴"这两种写法，单独发不触发
#刻晴图鉴角色也是同一套查询逻辑，出专门的角色资料卡（见下方）

别名 / 简称

别名表在 resources/alias/{{game}}.yaml，整理自 miao-plugin（MIT）；自己加的写 config/alias/{{game}}.yaml，格式一样

#护摩预置的角色专武叫法、圣遗物套装简称，比如"护摩"→护摩之杖、"辰砂"→辰砂往生录
#苍白容易和闲聊常用词撞车的简称是"弱别名"（配置里前面带 #），只在消息带 # 或"图鉴"时才生效
苍白弱别名单独发不会触发，避免聊天时手滑误查（"苍白套"这种圣遗物简称除外，本身就是弱别名的固定搭配）

角色图鉴 NEW

专门的角色资料卡：称号、命之座、生日、所属、定位、CV、满级属性、全部突破材料、天赋、命之座效果、观测枢自己的推荐武器/圣遗物（不含任何第三方持有率统计），配色跟着角色主题色走

#刻晴图鉴角色立绘优先用观测枢自己的图（每个角色都有），没有再用喵喵插件本地立绘兜底
#刻晴天赋这类细分查询暂未支持，天赋/命座信息已经在角色卡里了

特色料理

奇怪/美味品质和特色料理（比如"普茹斯蒂司""奇怪的致水神"）在观测枢里没有单独条目，插件后台建了索引

普茹斯蒂司直接搜料理名，出这道料理自己的卡片（自己的图、效果、获得方式，并注明所属原料理）
·索引在插件启动后于后台建立，首次安装要等几分钟才能搜到全部

版本表

分类列表里的上线版本数据来自 genshin-db（MIT），观测枢本身不提供版本信息

#更新图鉴目录立即同步一次版本表；插件每天零点也会自动同步，#图鉴更新 会顺带触发
·数据存在 resources/version/{{game}}.yaml（运行时生成，不进 git）；自己补充/修正写 config/version/{{game}}.yaml

管理命令 仅主人

#图鉴更新重新拉取目录，顺带同步一次版本表；#图鉴强制更新 额外清空全部详情缓存
#更新图鉴目录只同步版本表，不刷新目录
#图鉴清除缓存清空全部条目详情缓存；#图鉴清除缓存护摩之杖 只清这一条，下次查询时重新拉取
#图鉴调试护摩之杖导出该条目新旧接口原始数据和结构摘要，方便反馈接口结构变化
#更新图鉴或 #强制更新图鉴，从 git 远程更新插件本身并重启（需 git clone 安装），和上面刷新数据的命令是两回事

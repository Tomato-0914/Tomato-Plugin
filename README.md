# obc-plugin · 观测枢图鉴

Yunzai-Bot（TRSS-Yunzai / Miao-Yunzai）图鉴插件。查询时实时读取米游社观测枢的数据，用 Yunzai 自带的渲染器出图，不需要下载图库，官方更新后这边自动跟上。

目前支持：原神。星铁的数据源已经预留（`model/obc.js` 里的 `ObcSource`），后续加一个 app 即可。

## 安装

把整个 `obc-plugin` 文件夹放到 Yunzai 根目录的 `plugins/` 下，重启 Yunzai。

不需要额外装依赖：用到的 `yaml` 和渲染器都是 Yunzai 自带的。需要 Node.js 18 或更高版本（用到了内置 `fetch`）。

## 指令

| 指令 | 说明 |
| --- | --- |
| `#胡桃图鉴` / `#图鉴胡桃` | 查询条目，支持别名和模糊匹配（`#雾切图鉴`） |
| `#武器图鉴` | 列出某个分类下的全部条目 |
| `#图鉴分类` | 查看观测枢有哪些分类 |
| `#原神图鉴` / `#图鉴帮助` | 帮助 |
| `#图鉴更新` | 重新拉取目录（主人） |
| `#图鉴强制更新` | 清空详情和图片缓存后重新拉取（主人） |
| `#图鉴调试胡桃` | 导出该条目的原始数据和结构摘要（主人） |
| `#更新图鉴` / `#强制更新图鉴` | 从 git 远程更新插件并重启（主人，需 git clone 安装） |

武器条目会用专门的横版武器模板出图（名称、星级、类型、满级属性、技能、获取途径、全部升级材料、推荐角色）；`#更新图鉴` 是升级插件本身，和 `#图鉴更新`（刷新目录数据）是两回事。

## 配置

`config/default.yaml` 是默认配置，升级时会被覆盖。要改的话新建 `config/config.yaml`，只写想覆盖的项，例如：

```yaml
priority: 50
render:
  width: 900
```

改完配置不用重启（`priority` 除外）。

常用项：

- `priority`：默认 -10，会抢在逍遥、喵喵等插件前面接管“#xx图鉴”。
- `render.imageProcess`：让米游社 CDN 先缩图再传，省带宽。图片显示不出来就设成 `''`。
- `render.excludeSections`：不想渲染的分段（默认跳过角色故事、配音/语音、关联词条）。
- `render.removeSelectors`：渲染前从正文里删掉的元素。
- `api.detailIdSplit` / `games.gs.newBase`：新旧数据源的分流阈值和新接口地址，一般不用动。
- `weapon.width`：武器图宽度，默认 1280。
- `weapon.domainDays`：突破材料对应的秘境开放日，显示在“升级材料”标题后；新地区的材料在这里补上即可。

## 别名

自带别名在 `resources/alias/gs.yaml`。自己加的写到 `config/alias/gs.yaml`，格式相同，升级不会覆盖：

```yaml
雷电将军: [雷神, 将军]
```

名称的一部分（比如“雾切”→ 雾切之回光）不用写，插件会自动模糊匹配。

## 缓存

都在 Yunzai 根目录的 `data/obc-plugin/gs/` 下：

- `index.json`：目录，默认 6 小时刷新一次
- `detail/`：条目详情（新旧两套接口拉下来后都规范成同一结构存这里），默认 12 小时
- `render/`：渲染好的图片。正文、模板或渲染配置变了会自动重新渲染，没变就直接发缓存

接口请求失败时会先用旧缓存顶上。插件升级后如果详情的解析结构变了，旧的详情缓存会自动重新拉取。

`#xx图鉴` 没有命中任何条目时不回复，交给其他插件处理；`#图鉴xx` 没命中时才会给出相近条目的提示。

## 数据源说明

观测枢的内容分成了两套接口，插件会自动按条目 id 分流：

- 旧条目（id < `api.detailIdSplit`，约 5900 条）走 `blackboard` 的 `content/info`，正文是整段 HTML；
- 新条目（id ≥ 500000，约 7700 条，娜维娅、薇斯纳、伊涅芙等都在这里）走 `hoyowiki` 的 `entry_page`，正文是一套结构化模块（基础信息 / 天赋 / 命之座 / 角色故事N / 配音展示 …），插件会先把它转成和旧版一致的结构再渲染。

主接口报“内容不存在”时，会自动换另一套接口再试一次。

## 已知情况

- 目录、详情、匹配、清洗链路都已连真实接口跑通，新旧条目都能正常查询。
- 观测枢正文是 HTML / 结构化模块，目前按通用规则清洗后统一渲染；分区查询（只看天赋、命座等）还没做——新版模块名（天赋、命之座）已经非常规整，做起来不难。
- 角色条目的“角色展示 / 配音”等分段体积较大，会切成多张长图；嫌多可以往 `render.excludeSections` 里加。
- 使用的是米游社非公开接口，随时可能变动；接口结构变了发 `#图鉴调试名称` 把结果反馈过来。
